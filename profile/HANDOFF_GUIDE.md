# 交接指南

Codex 与 Claude 共用；交接或接手时读。研究阶段结束、反复压缩或用户要求时考虑换线程，先向用户提议。交接只更新已有文件。

## 怎么交

- 当前任务 README 写清目标、终点、已有结果、证据路径、未决问题和下一件事；科学数字及分母留在结果文件，负结果和失败也保留。
- `START_HERE.md`（旧项目沿用原入口）只保留短索引：日期、研究问题、活跃任务、当前方法/授权、待决定事项和下一步。链接任务 README，不复制完整现状，不另建 handoff 文件。
- 有意义的决定、结果、失败与阻塞在发生时记一次。交接检查受影响的状态、证据、有效约束、方法版本及路径；没有新事实就不再写一份总结。

## 怎么接

- 遵守适用 AGENTS；已完整提供且未变的规则视为已读。缺失、适用目录变化或有更新迹象才重读。读入口后，只开当前任务需要的文件；大历史按问题检索。
- 入口与证据冲突时，核对当前方法、授权及其有权作出的后续决定。记录日期较新不自动覆盖冻结方法或授权；不能判断时保留分歧，先做不受影响的工作。
- 第一条回复简述当前决定和下一步，然后推进已授权工作。

旧线程给入口的本机绝对路径和一句可直接发给新线程的话，例如“从该项目 START_HERE.md 接手当前任务”。
